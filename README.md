# Meta Soil

แอป Flutter สำหรับอ่านและจัดการข้อมูลจากเซนเซอร์วัดดิน CH340 ผ่าน USB แสดงผลค่าความชื้น อุณหภูมิ pH, EC, Salinity, Nitrogen, Phosphorus และ Potassium พร้อมตำแหน่ง GPS แผนที่ ประวัติในเครื่อง และการส่งข้อมูลไปยัง Data Hub

## ความสามารถหลัก

- อ่านค่าจากเซนเซอร์ USB และแสดงสถานะการเชื่อมต่อ
- บันทึกผลการวัดพร้อมชื่อแปลง วันเวลา และตำแหน่ง GPS
- เก็บประวัติไว้ในเครื่องและคงรายการที่ยังส่งขึ้น Data Hub ไม่สำเร็จ เพื่อรอส่งภายหลัง
- ส่งข้อมูลแบบกลุ่มไปยัง Data Hub ที่ตั้งค่าไว้ พร้อมเลือกการส่งอัตโนมัติหรือส่งเอง
- ค้นหาและกรองประวัติตามชื่อแปลงและวันที่ รวมถึงจัดการหมุดแผนที่โดยไม่ลบประวัติการวัด
- ส่งออกและแชร์ประวัติเป็น CSV หรือ JSON
- รองรับภาษาไทยและอังกฤษ และปรับหน้าจอตามโทรศัพท์หรือแท็บเล็ต

## เริ่มต้นใช้งาน

```bash
flutter pub get
flutter run
```

บน Android ต้องเชื่อมต่อเซนเซอร์ผ่าน USB Host/OTG และอนุญาต USB ให้แอปเมื่อระบบถาม ส่วนการส่งข้อมูลต้องตั้งค่า URL และ API key ของ Data Hub ในหน้าตั้งค่าของแอป

### `Meta_Soil_1.1` — `18f2cb0`

**เพิ่มระบบบันทึกและส่งข้อมูล พร้อมปรับแบรนด์เป็น Meta Soil**

- ปรับชื่อแอป สี โลโก้ ไอคอน และหน้าเปิดแอปสำหรับ Android, iOS และเว็บ
- เพิ่มชื่อให้แต่ละรอบการวัด และเก็บชื่อไว้กับข้อมูลการวัดเพื่อใช้ในประวัติ แผนที่ และข้อมูลที่ส่งออก
- ปรับการอ่านค่าให้เก็บตัวอย่างเป็นชุด มีการหน่วงจังหวะอ่านและนับถอยหลัง พร้อมยกเลิกการวัดที่ได้ตัวอย่างไม่ครบได้
- เปลี่ยนจาก dependency ของ Firebase/Firestore มาใช้ Data Hub ผ่าน HTTP เพิ่มหน้าตั้งค่าและทดสอบการเชื่อมต่อ และส่งค่าทั้ง 8 รายการพร้อมชื่อการวัด เวลา และข้อมูล GPS เป็นชุดเดียว
- ปรับการเก็บประวัติแบบ local-first: เก็บข้อมูลที่ยังไม่ซิงก์ไว้ ไม่ตัดรายการที่ยังส่งไม่สำเร็จ และจัดคิวการเขียนเพื่อป้องกันข้อมูลทับกัน
- เพิ่มหน้าประวัติในเครื่อง การค้นหา/กรอง การจัดกลุ่มตามชื่อแปลง และการลบประวัติในเครื่อง
- เพิ่มการส่งออกและแชร์ CSV/JSON พร้อมหัวตารางและข้อมูลภาษาไทย/อังกฤษ
- ปรับหมุดแผนที่ให้จัดกลุ่มตามชื่อการวัด แยกหมุดที่อยู่ใกล้หรือซ้อนกัน และไม่สร้างหมุดให้รายการที่ไม่มี GPS
- เพิ่มการทดสอบสำหรับการส่ง Data Hub, การวัด, การเก็บประวัติ, การส่งออก และการจัดการหมุด

### `Meta_soil_1.5_Phoneavailable` — `7647635`

**เพิ่มเลย์เอาต์แดชบอร์ดสำหรับโทรศัพท์**

- จัดหน้าโทรศัพท์แนวตั้งให้เห็นแผนที่ แถบ GPS ช่องชื่อแปลง ปุ่มวัด และการ์ดเซนเซอร์ 8 ค่าในพื้นที่แคบ โดยเลื่อนหน้าได้เมื่อความสูงไม่พอ
- จัดหน้าโทรศัพท์แนวนอนใหม่ พร้อมเปลี่ยนจำนวนคอลัมน์ของการ์ดตามความกว้าง
- เพิ่มปุ่มวัดขนาดกะทัดรัด แสดงสถานะและเวลานับถอยหลัง และปรับขนาดข้อความ/ไอคอนของการ์ดสำหรับมือถือ
- คงรูปแบบการ์ดเดิมสำหรับแท็บเล็ต และเพิ่มการทดสอบตำแหน่งปุ่ม การ์ด ค่า และหน่วยในแนวตั้ง/แนวนอน
